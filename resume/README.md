# Bryan Yang Resume

参考 `resume.rizumu.me` 的双栏信息架构制作的静态个人简历。

## 本地预览

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 修改内容

- 个人信息、简介、项目和经历：编辑 `index.html`。
- 色彩、布局与打印样式：编辑 `styles.css`。
- 邮箱、主题和打印交互：编辑 `script.js`。
- 点击页面右下角的 `PDF` 按钮，可调用浏览器打印并保存为 PDF。

当前内容依据公开 GitHub 资料生成。正式投递前，建议补充真实公司名称、任职时间和可量化的业务成果。
